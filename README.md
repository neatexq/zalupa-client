# Zalupa Client

Кастомный клиент [DDNet](https://ddnet.org).

## Установка

Скачай `ZalupaClient-Setup.exe` из [последнего релиза](https://github.com/neatexq/zalupa-client/releases/latest) и запусти.
Права администратора не нужны. Дальше клиент обновляется сам.

Если Windows покажет «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае» (установщик не подписан).
